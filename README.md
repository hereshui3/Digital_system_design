# 数字系统设计

西安交通大学微电子学院大二数字系统设计实验课代码，基于 Verilog HDL，运行于 Xilinx EGO1 FPGA 开发板。

## 项目

- **Comparator** — 2位比较器
- **Full Adder** — 1位全加器
- **expe2** — 4-2编码器
- **LED** — LED闪烁控制
- **Breath LED** — PWM呼吸灯
- **Stopwatch** — 数字秒表
- **Smart Responder** — 四人抢答器
- **Traffic Light** — 交通灯控制器
- **VGA** — VGA彩条显示
- **Runner Game** — 跑酷小游戏
